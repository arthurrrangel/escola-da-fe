## 🎯 Sobre o Projeto

O **Escola da Fé** é uma escola bíblica online com:

- **12 Módulos** de formação bíblica progressiva
- **93 Aulas** com múltiplos professores especialistas
- **Vídeos introdutórios exclusivos** por módulo (somente membros)
- **Provas de avaliação** em cada bloco
- **Certificado de conclusão** oficial
- **Comunidade exclusiva** de membros
